### Вывод

В ходе лабораторной работы я протестировал три платформы для работы с LLM через API и UI. Для дальнейшей работы и повседневных задач я выбрал **Groq (Qwen 3.8-27b)**, так как эта модель продемонстрировала наилучшую скорость генерации ответа (всего **3.09 секунды** на **1432 токенов**), значительно опередив конкурентов. Больше всего меня удивило то, что веб-интерфейс Google AI Studio потребовал оформления подписки даже для отправки базовых промптов вручную. В то же время запуск запросов через программный API и использование Groq оказались максимально удобными и высокопроизводительными инструментами.
